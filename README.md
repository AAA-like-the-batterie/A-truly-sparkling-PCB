# What does it do ?
* When the button on the botton is push, the LEDs light up and if you push the second button, the motor will started to make vibration (yes, it's quite simple).


# Bill of materials  ?
* 2 LED
* 2 push button
* 1 batterie cell holder
* 2 resistors
* 1 vibration motor
